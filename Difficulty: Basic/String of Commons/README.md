<p><span style="font-size: 18px;">Uppercase and lowercase characters are considered different. </span><span style="font-size: 18px;">If there is no common character, return an empty string.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s1 = "tUvGH", s2 = "Hhev"<strong>
Output: "</strong>Hv"<strong>
Explanation: </strong>The common characters are 'H' and 'v'.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s1 = "aabb", s2 = "ccll"<strong>
Output: </strong>""<strong>
Explanation: </strong>There is no common character, so return an empty string.</span></pre>
